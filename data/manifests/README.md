# Manifests

`split_v1.json` is generated by:

```bash
uv run python -m triage.cli split --incidents data/processed/incidents.parquet --out-dir data/processed --manifest data/manifests/split_v1.json --sample-size 100000
```

The manifest is frozen after the GUIDE run. It records source hashes, split file hashes, row counts, label counts, incident-id hashes, the sampling seed, and whether the test split is official or locally carved.

Do not edit the committed manifest by hand. Rebuild it with `--force` only when intentionally changing the frozen split, and update the report that compares against it.

Fixture manifests are written under `reports/fixture_run/manifests/` and are not the real artifact.
