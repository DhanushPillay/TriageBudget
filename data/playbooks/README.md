# Synthetic triage playbooks

These playbooks are synthetic guidance written for the TriageBudget portfolio
project. They are not an operational SOC policy, a vendor runbook, or a claim
about GUIDE remediation labels. Each file uses a stable section format so the
retrieval index can cite a specific section.

Metadata fields:

- `Categories`: GUIDE category tokens that select this playbook.
- `Role`: intended reviewer.
- `Source`: synthetic.
- `Effective`: review date for this project.
